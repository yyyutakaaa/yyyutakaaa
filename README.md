Muted is my main project and the one I'm most proud of

It cleans up your microphone in realtime using RNNoise, so people on the other end hear you and not your keyboard, fan or background

| | |
|---|---|
| **Realtime** | Noise suppression on your mic while you talk |
| **Local** | Everything runs on your own PC |
| **No cloud** | Nothing leaves your machine |
| **No account** | Install it and go |
| **No recordings** | No audio is ever recorded |
